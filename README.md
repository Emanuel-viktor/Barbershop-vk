## 🎯 Sobre o Projeto

O Sistema esta sendo desenvolvido para colocar em pratica os conhecimento na parte de desenvolvimento para web.

A plataforma centraliza informações relacionadas a:

- 👤 Usuario
- 📅 Agendamentos
- 📋 Fila
- 📊 Indicadores Gerenciais

O objetivo é gerenciar os agendamentos de uma barbearia e mostrar relatorios.

## 🏗️ Arquitetura

O projeto segue uma arquitetura em camadas:

```text
Controller
    ↓
Service
    ↓
Repository
    ↓
PostgreSQL
```

Estrutura principal:

```text
src
├── entities
├── repositories
├── services
├── resources
├── dto
├── enums
└── config
```
